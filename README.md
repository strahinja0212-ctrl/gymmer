# Teg po teg

A beginner gym program in Serbian, as a single HTML file. It runs in any browser, and no install is needed.

- **Trening:** a 4-day upper/lower split. Mark each set as you finish it, and a rest timer starts. Every exercise has how-to steps and a link to form videos.
- **Ishrana:** a calorie and macro calculator, plus a 3-day meal plan whose portions scale to your target.
- **Dnevnik:** your workout log, with a progress chart for each exercise and JSON export/import for backups.
- **Saveti:** training rules, weekly sets per muscle, and answers to common questions.

Pick a red, blue or yellow theme from the header.

Your data stays in your browser's localStorage. Use export/import to move it between devices.
